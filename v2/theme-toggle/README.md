# theme-toggle

Light/dark and theme-list shortcuts.

| Key | Action |
| --- | --- |
| `alt+v` | toggle light/dark mode (dispatches `theme.switch_mode`) |
| `alt+t` | open the theme list (dispatches `theme.switch`) |

Palette commands: `theme.toggle.mode`, `theme.switch.list`.

## Install

Copy `v2/theme-toggle` to `.opencode/plugins/theme-toggle/`.
